## Growth Idea

### Add Restaurant + LocalBusiness Schema to Landing Page

**Current state:**
- Only `@type: Organization` schema present
- No geographic, service-area, or cuisine-type markup
- No aggregate rating schema (chef reviews not connected to search)
- No FAQ schema for "How does booking work?" rich snippets

**Proposed change:**
Add three complementary schemas to `page.tsx`:

1. **`LocalBusiness`** — Geographic and service-area signals
   - `name`, `address` (Montreal), `geo` (lat/lng), `areaServed: Montreal`
   - `priceRange: $$$`
   - `telephone`, `email`

2. **`Restaurant`** — Extends LocalBusiness with dining-specific signals
   - `servesCuisine: French, Italian, Contemporary, etc.`
   - `hasMenu` reference to experience types

3. **`FAQPage`** — Answers to common search queries as rich snippets
   - "How do I book a private chef?"
   - "How much does a private chef cost in Montreal?"
   - "What types of events can a private chef handle?"

**Why this matters:**
- "Private chef Montreal" is a high-intent local search query — rich results with address, hours, and aggregate ratings outperform plain listings
- FAQPage schema creates position-zero snippet opportunities in search results
- Restaurant + LocalBusiness together signal to Google that this is a service-area business, not just a generic website
- Zero backend changes, no risk, deploy-and-forget SEO infrastructure

## Implementation Details

**File to modify:** `src/app/page.tsx`

**Changes:**
1. Replace the single `organizationSchema` with three schemas: `localBusinessSchema`, `restaurantSchema`, `faqSchema`

**No new dependencies:**

- No runtime JavaScript — all server-rendered
